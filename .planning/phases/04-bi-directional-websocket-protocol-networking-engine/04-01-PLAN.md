<objective>
Implement the embedded WebSocket server, cryptographic session authenticator, and versioned JSON-RPC protocol engine in vscode-extension/. Provide loopback (127.0.0.1) USB connectivity by default, dynamic port collision fallback (ports 38848-38855), token-based authentication for optional LAN connections, heartbeat/ping-pong monitoring, and automated broadcasting of EditorMonitor telemetry events to all authenticated Android companion clients.

Purpose: Establishes the host-side networking foundation so the Android companion device can maintain a persistent, low-latency, secure data stream with VS Code for real-time telemetry and command responses.
Output: Artifacts this plan produces:
- vscode-extension/src/network/protocol.ts (Versioned JSON-RPC protocol envelope definitions, error codes, and message factories)
- vscode-extension/src/network/authManager.ts (Token generation, pairing verification, and loopback/LAN boundary enforcement)
- vscode-extension/src/network/serverManager.ts (WebSocketServer lifecycle, port retry, client tracking, and event broadcaster)
- vscode-extension/test/network.test.ts (Unit tests for protocol framing, authentication, and server message routing)
</objective>
