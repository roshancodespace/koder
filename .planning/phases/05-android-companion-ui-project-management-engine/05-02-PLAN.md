<objective>
Implement the multi-source project importer and hierarchical tree parser in companion-app/. Provide extraction from local directory paths, local ZIP archives via the archive package, remote ZIP URLs via http, and GitHub repository archives. Parse relative file paths into a nested hierarchical tree with default ignore rules (.git, node_modules, build), parent-to-child exclusion inheritance, and Riverpod state management.

Purpose: Enables developers to import codebases onto their Android companion device from any source and navigate or filter files with exclusion rules.
Output: Artifacts this plan produces:
- companion-app/lib/features/project/services/tree_parser_service.dart (Hierarchical tree structure, parent-child linking, and exclusion inheritance)

- companion-app/lib/features/project/providers/project_provider.dart (Riverpod state notifier for active project, nodes, and exclusions)
- companion-app/test/unit/tree_parser_test.dart (Unit tests for tree structure, nesting, and exclusion propagation)
