<objective>
Implement the native Kotlin Bluetooth HID Device platform channel (BluetoothKeyboardManager) in companion-app/ to turn the Android device into a low-latency hardware keyboard. Establish defensive capability probing for OEM Bluetooth HAL support (API 28+), configure Service Discovery Protocol (SDP) settings with a standard 8-byte boot keyboard report descriptor, implement scancode transmission with immediate release report cycling, and expose MethodChannel/EventChannel bindings to a Riverpod-backed Dart BluetoothHidService.

Purpose: Delivers the core hardware keyboard capability of the companion system, enabling the Android device to send native keyboard shortcuts directly to the workstation OS.
Output: Artifacts this phase produces:
- companion-app/android/app/src/main/kotlin/com/companion/companion_app/BluetoothKeyboardManager.kt (Native HID device manager)
- companion-app/android/app/src/main/kotlin/com/companion/companion_app/MainActivity.kt (Platform channel registration)
- companion-app/lib/features/bluetooth_hid/models/hid_state.dart (Connection state and capability data classes)
- companion-app/lib/features/bluetooth_hid/bluetooth_hid_service.dart (Dart client for MethodChannel & EventChannel)
- companion-app/test/unit/bluetooth_hid_service_test.dart (Unit test suite for HID models and channel mock verification)
</objective>
