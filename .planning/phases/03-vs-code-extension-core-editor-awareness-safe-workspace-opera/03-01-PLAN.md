<objective>
Implement the core workspace safety engine and event-driven editor monitor in vscode-extension/. Build the PathValidator enforcing canonical URI containment inside workspace folders to block directory traversal attacks (../), build SafeWorkspaceManager providing collision-safe file creation via vscode.workspace.fs (disallowing implicit overwrites and creating parent directories recursively), and build EditorMonitor emitting real-time editor telemetry (active document, language, cursor, selection, diagnostic error/warning counts) with 250ms debouncing.

Purpose: Establishes safe workspace operations and context awareness so the companion system can monitor editor activity and manipulate files without security vulnerabilities or data loss.

- vscode-extension/src/workspace/pathValidator.ts (Path traversal defense and workspace boundary validation)
- vscode-extension/src/workspace/safeFileManager.ts (Collision detection, recursive directory creation, and safe writing)
- vscode-extension/src/editor/editorMonitor.ts (Debounced editor telemetry and diagnostics listener)
- vscode-extension/test/workspace.test.ts (Unit tests for path validation and collision detection)
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Input / Remote Command -> Workspace Filesystem | Unsanitized file paths could escape the active workspace directory and overwrite or create arbitrary system files. |
| Host Editor Events -> Telemetry Stream | Rapid editor typing events could cause Denial of Service (high CPU/event loop starvation) without debouncing. |
